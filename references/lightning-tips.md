# UI automation is retired

This workflow does not open Lightning, click tabs, or fill TinyMCE.

Use the Chrome `sid` cookie and the objects in [objects.md](objects.md). Appointment text comes from SOQL. The article is a REST insert into `Knowledge__kav`. Related Categories go through `CaseFeedArticleController.upsertAndDeleteProductTaggings`.

Do not install or call Playwright MCP for a Knowledge Article.
